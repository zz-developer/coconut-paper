We first introduce the general structure of modern large language models (LLMs) to better demonstrate our approach and paradigm.

Modern LLMs involve the Embedding layer; Core Transformer, including Self-Attention and FFN; and the Output linear layer which project the latent state vector of $\mathrm{embed\_\dim}$ to probability distribution of $\mathrm{vocab\_size}$ layers, as we denote them $\boldsymbol{E}$, $\boldsymbol{M}_n$, and $\boldsymbol{O}$ respectively, where $n$ indicates the layer of hidden state~\citep{DBLP:journals/corr/VaswaniSPUJGKP17, radford2019language}.

We preliminarily perform prefilling by the question with the length $q_0$ into the model, and get the prefilled KV Cache~\citep{pope2022efficientlyscalingtransformerinference} and the probability distribution of the answer's first token $t_{q_0+1}$ (starting to count from $t_1$).

After extracting the hidden state $\boldsymbol{h}_{n_0,q_0}$ (where $n_0$ denotes the layer number of the Transformer and $q_0$ denotes question length), we deliver the state to a Variational Autoencoder~\citep{DBLP:journals/corr/abs-1906-02691} (we will introduce it in~\ref{subsubsec:vae-layer}), and produce a vector for storage with length $l_s$.

\subsubsection{Variational Autoencoder Layer}\label{subsubsec:vae-layer}

We use Variational Autoencoder (VAE)~\citep{DBLP:journals/corr/abs-1906-02691} to compress and uncompress the hidden state token $\boldsymbol{h}_{n,k}$, which is a $l_h$-dimensional vector, to a $l_c$-dimensional vector and then back to $l_h$.

\begin{figure}[btbp]
    \centering
    \includegraphics[width=0.5\textwidth]{./figures/VAE}
    \caption{The VAE layer.
    We firstly compress the hidden state to a lower dimension (expand into $4$ times of original size and then compress), extracting the compressed vector, and use the symmetric approach to expand it back to the original dimension.}
    \label{fig:vae}
\end{figure}

The VAE layer looks like a bottleneck-like layer, which is used to compress the hidden state to a lower dimension and then expand it back to the original size.
The shape of the VAE layer in our work can be described in Figure~\ref{fig:vae}.

We pretrain the VAE on the online-generated activation of $1024$ consequences, and the validation loss decreased steadily, proving that the pretraining process of the VAE does not require much data.
We will provide supplemental data demonstrating its effectiveness in the appendix.

\paragraph{Long-term Cache}

During sampling, we will store the latent space activation output from later $n_0$ for further paralleled training.
Yet directly storing the raw vector of $\mathrm{embed\_\dim}$ could be space consuming.
(see \footnote{Consider a sample batch size of $1024$, sequence length $1024$, and embedding dimension $1536$. Each element occupies \qty{2}{bytes} (BF16), resulting in $1024\times1024\times1536\times2 = 2^{31.5}$ bytes, or approximately \qty{2.8}{GB} of VRAM.
In contrast, if we adapt the VAE layer to compress the hidden state to $256$ dimensions, we only need $1024\times1024\times256\times2 = 2^{29}$ bytes, or approximately \qty{512}{MB} of VRAM.
} for quantitative analysis of the space consumption),

We store it in each operation, and concatenate these vectors into a matrix subsequently as a hidden state.

\subsubsection{Gating Mechanism}\label{subsubsec:gating-mechanism}

Our model introduces two gates: the update gate and the Dynamic Current Step Mixing Gate.

\begin{enumerate}
    \item \textbf{Update Gate.} Inspired by Gated Recurrent Unit (GRU)~\citep{zhang2023dive_gru, DBLP:journals/corr/ChungGCB14, DBLP:journals/corr/ChoMBB14}, the update gate is used to increase its contextual consistency in patent space, but the value of the gate is derived from the sequence.
    We denote it as $\boldsymbol{g}_t$, and its derivation procedure can be described in Equation (not yet).
    We initialize it to all zeros, i.e., initially the model is equivalent to the original one, but it evolves as $\boldsymbol{g}$ moves away from $\boldsymbol{0}$.
    \item \textbf{Dynamic Current-Step-Mixing Gate (DMG).}
\end{enumerate}

The processed vector $\boldsymbol{h}^\prime_{n,k}$ after the VAE layer is passed to several gates, as we denote in Equation~\ref{eq:gate}.

\begin{equation}
    \boldsymbol{h}^\prime_{n,k} = \boldsymbol{h}^\prime_{n,k-1} \odot \boldsymbol{g} \odot \mathrm{DMG}(\boldsymbol{e}_k) \times
    s_\mathrm{inj}
    + \left(1-\boldsymbol{g}\right) \odot \boldsymbol{e}_k
    \label{eq:gate}
\end{equation}

where $\boldsymbol{e}_k=\mathrm{Embedding}(\boldsymbol{t}_k)$; $\boldsymbol{t}_k$ denotes the token of sequence with position $k$, and $s_\mathrm{inj}$ denotes injection scalar, which is a constant scalar to bridge the difference in order of magnitude among gating value and the result of Dynamic Current-Step-Mixing Gate, which will be described in Section~\ref{subsubsec:gating-mechanism}.

\subsection{Training}\label{subsec:training}

We use the DAPO objective as our reinforcement learning framework, but the whole procedure is slightly different from the original DAPO.
The whole training procedure is described in Algorithm~\ref{alg:training}.

\begin{algorithm}
    \caption{Training Procedure taking one batch as an example.\label{alg:training}}
    \KwData{Given a sequence $S$ of $\mathrm{seq\_length}$, where $\boldsymbol{t}_k\in S$; $\boldsymbol{t}_k$ denotes token index.}
    \KwResult{Model}
    $\boldsymbol{e} \leftarrow \mathrm{Embedding}(\boldsymbol{s}\mathtt{[\colon-1]})$\;
    $\boldsymbol{h} \leftarrow \boldsymbol{E}(\boldsymbol{e})$\;
    $p \leftarrow \mathrm{Softmax}(\boldsymbol{O}(h))$\;
    $loss \leftarrow \mathrm{CrossEntropyLoss}(p, \mathrm{one\_hot}(\mathtt{[\colon-1]}))$\;
    Optimize by minimizing $loss$\;
\end{algorithm}

\subsubsection{Reinforcement Learning}

We parallelized several inference procedures simultaneously, preferably $16$ for a same question, and verify the answer~\citep{Kydlicek_Math-Verify_Math_Verification}.

\paragraph{Training Objective}

We adapt the DAPO~\citep{yu2025dapoopensourcellmreinforcement} objective, but we have not already implemented the clip mechanism, which is used to clip the reward and penalty to a certain range.
Hence, we currently use the original DAPO objective, which is shown in Equation~\ref{eq:dapoloss}.

\begin{equation}
    \begin{aligned}
        \mathcal{J}_{\mathrm{DAPO}}(\theta) =\quad& \mathbb{E}_{(q,a)\sim \mathcal{D}, \{o_i\}_{i=1}^G\sim \pi_{\theta_\mathrm{old}}(\cdot\mid q)}\\&
        \frac{1}{\sum_{i=1}^{G}|o_i|}\sum_{i=1}^{G}\sum_{t=1}^{|o_i|} r_{i,t}(\theta) \hat{A}_{i,t}
        \\
        \mathrm{subject\ to}\quad& 0< \left|\{o_i\mid\texttt{is\_equivalent}(a,o_i)\}\right|< G,
        \label{eq:dapoloss}
    \end{aligned}
\end{equation}
where
\begin{equation}
    r_{i,t}(\theta)=\frac{\pi_{\theta}(o_{i,t} \mid q, o_{i,<t})}{\pi_{\theta_{\mathrm{old}}}(o_{i,t} \mid q,o_{i,<t})},\quad\hat{A}_{i,t} = \frac{R_i - \mathrm{mean}(\{R_i\}_{i=1}^G)}{\mathrm{std}(\{R_i\}_{i=1}^G)}.
    \label{eq:advantage_calculation}
\end{equation}

\paragraph{Award Mechanism}

We use $\mathrm{reward}_{\mathrm{acc}}$ and $\mathrm{penalty}_{\mathrm{len}}$ to award or penalize in accuracy, according to DAPO~\citep{yu2025dapoopensourcellmreinforcement}.
The exact value of the reward and penalty will be described in appendices.

\paragraph{Positive-Negative Clipping}

To eliminate the issue of too much negative samples (which each holds less use to the model's improvement) under a budget-tight scenario, we only choose all the positive samples, and randomly choose the rest negative samples according to the ratio $1:1$.

\subsubsection{Time Consistency Regularization}

We adapt a mechanism called ``Gating Value Bonus,'' which is used to let the model make full use of the information from latent space instead of setting stuck in the local optima of not using the space sufficiently.

The gating value bonus is a regularization term that encourages the gating values to be close to the middle, as the formulation is shown in Equation~\ref{eq:gating-value-bonus}.

\begin{equation}
    \mathcal{J}_{\mathrm{gate}}\left(\boldsymbol{g}\right)=\dfrac{1}{\mathrm{output\_dim}}C_0\displaystyle\sum_{i=0}^{\mathrm{output\_dim}}\exp\left[\lambda\left(\dfrac{1}{2}-g_i\right)^2\right]
    \label{eq:gating-value-bonus}
\end{equation}

where $g_i=\boldsymbol{g}\cdot\boldsymbol{e}^{(i)}$, i.e., the $i$-th element of the gate vector $\boldsymbol{g}$, and $C_0$ is a constant to control the scale of the bonus; $\lambda$ is a constant to control the rate of convergence.
