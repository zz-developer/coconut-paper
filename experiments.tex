\subsection{Setup}\label{subsec:setup}

\paragraph{Base Model} We use Qwen3-4B~\citep{qwen2, qwen2.5, qwen3} as our base model, which is a 4B-parameter model with $24$ layers.
DeepSeek distilled the model into an explicit reasoning model~\citep{deepseekai2025deepseekr1incentivizingreasoningcapability}, which is our comparison baseline.

\paragraph{Baselines} We compare our model with the following baselines:

\begin{itemize}
    \item \textbf{Qwen3-1.7B}: The original model.
    \item Distillation method from~\citet{deepseekai2025deepseekr1incentivizingreasoningcapability} performed on Qwen3-4B.
    \item The original model with DAPO~\citep{yu2025dapoopensourcellmreinforcement} objective solely.
    \item Our model with DAPO algorithm, gating mechanism, and VAE layer.
    \item The original model with VAPO~\citep{yue2025vapoefficientreliablereinforcement} objective solely.
\end{itemize}
